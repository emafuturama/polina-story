# Сайт для Полины: что уже готово и как получить ссылку

В папке `polina-story` находится рабочая версия сайта. Её можно открыть через `index.html` на компьютере. После публикации по ссылке она будет доступна и на телефоне.

## Уже добавлено

- Семь глав, обложка и 21 игровой экран.
- Ник «тгк: wifiboy0», комментарий «зайди в лс», личное сообщение «давай познакомимся», аватарка с Наруто. Лишнего блока с профилем Полины внутри лички нет.
- Правильные ответы: Discord, плюшевый Аппа, Авиапарк, кораблик, Нахабино.
- 179 присланных фотографий. Избранные снимки открываются в соответствующих сценах, полный альбом доступен в финале. Фотографии показываются целиком; нажатие увеличивает снимок.
- Ваш трек «П+А=♡». Включается после нажатия на начало истории или кнопку музыки; есть пауза и регулировка громкости. Во время поздравления музыка приостанавливается.
- Одобренная фотография квартиры с тобой. Реплика стоит на стене выше лица. Отклонённый вариант с изменённой комнатой не используется.
- Настоящий 7-секундный MP4-переход в бекрумс: две PNG-фигурки, ваша фотография, исчезающие таблички четырёх городов. После видео открывается фото из кино.
- Выбранный тобой **IMG_7043.MOV**, повёрнутый в вертикальную ориентацию и сохранённый как `birthday-vertical.mp4`: 464 × 848, 33,6 секунды, с исходным звуком. После открытия глаз он играет во весь экран, в рамке с цветами и сердечками.
- Курьерская игра, самолётики, слезинки, интерактивная доска фотографий, календарь и финальное письмо.
- Полароиды в боковой колонке и гирлянды ваших снимков по страницам истории.
- Сохранение открытого этапа в этом браузере. На другом телефоне прохождение начинается отдельно.

## Три настоящие прогулки

Внутри сайта встроены панорамы и пешие маршруты Яндекс Карт. На каждой прогулке есть таймер 10 минут, пауза, карта пути, подсказка последнего поворота и разворачивание на весь экран. Переключение на карту сохраняет место в панораме. Для карт нужен интернет; собственный ключ API не требуется.

| Прогулка | Финиш | Доступные годы съёмки |
|---|---|---|
| Челябинск: от Пятёрочки | Братьев Кашириных, 131, подъезд 4 | У магазина 2025, у входа 2024 |
| Первая Москва: от Магнита | Вокзальная, 27А, частный дом | 2024 |
| Нахабино: от Красного & Белого | Пятый подъезд дома с присланной фотографии | У магазина 2024, перед входами 2023 |

В частном дворе на Вокзальной панорам нет: ближайшая съёмка идёт с улицы, а точка 27А отмечена на карте. У последнего дома различается нумерация: Google подписывает его как Белобородова, 17, Яндекс — как 14; выбран совпадающий фасад и нужный пятый вход.

Виджет Яндекса не сообщает сайту, дошла ли игрок до двери. Поэтому завершение честное: «Я дошла» → вопрос о вашем доме или выбор входа на фотографии → ваши воспоминания. Автоматической проверки положения нет.

## Что загружать на GitHub

Распакуй архив. Загружай **содержимое папки `polina-story`**, чтобы `index.html` оказался сразу в корне репозитория.

```text
index.html
style.css
app.js
story.js
library.js
routes.js
.nojekyll
assets/
  heart.svg
  photos/
  effects/
  maps/
  audio/
  video/
```

Папки `work` и исходный архив фотографий не нужны. ZIP целиком в репозиторий загружать не нужно — сайт должен видеть распакованные файлы.

## Как получить свою ссылку

1. Войди на GitHub и создай новый репозиторий, например `for-polina`. Для бесплатного GitHub Pages на GitHub Free нужен **Public**.
2. Выбери **Add file → Upload files** и загрузи перечисленные файлы и папку `assets`, сохраняя структуру папок. Затем сохрани загрузку через **Commit changes**. Если загружаешь через браузер, делай это партиями: сначала файлы сайта, затем отдельные папки с материалами. В одной загрузке — не больше 100 файлов; каждый файл — до 25 MiB.
3. Открой **Settings → Pages**.
4. В **Source** выбери **Deploy from a branch**. Укажи ветку **main**, папку **/(root)** и нажми **Save**.
5. После завершения публикации GitHub покажет адрес вида `https://ТВОЙ-НИК.github.io/for-polina/`. Эта одна ссылка работает и на компьютере, и на телефоне.
6. Открой ссылку с телефона и пройди историю. Музыка запускается после первого нажатия — это обычное ограничение мобильных браузеров.

Бесплатный адрес `github.io` уже является твоей отдельной ссылкой. Собственный адрес вида `polina-love.ru` можно подключить отдельно, если захочешь; для этого нужен свой домен.

GitHub Pages — публичный сайт, а не личная защищённая страница. Фото, музыка и добавленные точные адреса будут доступны через опубликованные файлы. Надпись «только для тебя» и запрет индексации не являются паролем. Если нужна реальная приватность, это надо выбрать до публикации.

Официальные инструкции: [публикация из ветки](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site), [адрес сайта](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages), [загрузка файлов и ограничения](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository).

## Перед тем как дарить

- Отметить точный день рождения в сентябре; маршруты уже добавлены.
- Проверить выбранные фото и подписи. Подбор сделан по присланным папкам.
- Подарочный режим уже включён: `demo: false`. Главы открываются постепенно, подпись рабочей версии скрыта. Для свободного просмотра можно временно поставить `demo: true`.
- Загрузить актуальные изменённые файлы в тот же репозиторий: адрес сайта останется прежним.

Главные настройки находятся в `story.js`, маршруты — в `routes.js`, список всех фотографий — в `library.js`. Программировать для загрузки готового сайта не нужно.

## Источники оформления

Интерфейс TikTok сделан как интерактивная реконструкция по присланным данным и [официальному примеру ленты TikTok](https://newsroom.tiktok.com/ja-jp/how-tiktok-recommends-videos). Статичный фрагмент официального примера использован как фоновая иллюстрация ленты. Настоящий аккаунт не подключён, сообщения никуда не отправляются.

Фотография квартиры и прозрачные фигурки подготовлены встроенной генерацией изображений по вашим исходникам; это монтажные элементы. Ролик бекрумс собран из этих изображений и анимированных подписей. Исходные фото в альбоме сохранены без ретуши.
